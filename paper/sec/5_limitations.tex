\section{Limitations and reproducibility}
All experiments ran on four CPU cores: one pretrained model (ViT-B/32), evaluation subsets of 800 images per set (binomial s.e. $\approx 1.1$ points at 90\,\% accuracy), 2\,000-image fine-tuning and mostly single seeds for E1/E2 (E3 has three). COCO ``captions'' are templated from box categories, not human captions, and the retrieval set has 73 distinct captions. Only the MLP activation is converted; attention, softmax and LayerNorm stay dense, so the converted blocks are hybrid rather than fully spiking, and the surrogate-gradient fine-tuning uses straight-through spikes on CPU rather than a neuromorphic simulator. The $\alpha$ fits use WeightWatcher's default power-law fitter; truncated-power-law fits failed for most matrices and are not reported. Code, token caches, run JSONs and the analysis scripts are in the repository; every number in the paper is produced by \texttt{scripts/mm\_analyze\_*.py} from the JSONs.
